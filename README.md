# A Reusable Business Assistant

One assistant design, set up for each new business by swapping in its own information.

> **Case study.** Source code is private. The business problem, the design decisions and the stack are documented here.

## The problem

Building every bot from a blank page repeats the same decisions: tone, scope, handoff, what the bot must never say.

## What was built

- **Reusable structure** for scope, tone and handoff
- **Business-specific data** loaded per client

## Stack

Conversational AI platform · LLM APIs

## Status

Template used as a starting point for new builds.
